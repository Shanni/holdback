How the store got Holdback

No checkout changes. The merchant adds one app block, and Holdback handles offers, bids and guarantees as escrow holds.

  1. Install the Holdback app. It ships a Shopify theme app extension.
  2. Theme editor → Product template → Add block → Apps → Holdback offers & bids. Drop it under Buy it now.
  3. Paste the market URL. Each product maps to a Holdback item by handle, a holdback.item_id metafield, or the block setting.
  4. Optional: listen for holdback:purchase to mark the order paid. This page does that for the toast and the bag badge.
